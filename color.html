Color

Hex Color

Hex color is a 6 digit code that represents a color
The first 2 digits represent the red value
The second 2 digits represent the green value
The last 2 digits represent the blue value
For example #FF0000 is red because the red value is at its max and the green and blue values are at their minimum
Websafe is in an RGB format and is a 3 digit code that represents a color
RGBA Color is done in a 0-255 0-255 0-255 and 0-1 formate. This stands for red green blue alpha
Syntax is easy: color: #aaa; or color: #fc8826;
Syntax is more challenging: color: rgba(135, 25, 200, .4);
